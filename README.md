# omz notes

Source code for my personal blog at https://omkz.github.io — catatan programming seputar Ruby, Rails, JavaScript, Database, dan lainnya.

## Tech Stack

- [Jekyll](https://jekyllrb.com/) 4.4
- [jekyll-timeago](https://github.com/markets/jekyll-timeago)
- Hosted on [GitHub Pages](https://pages.github.com/)

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
